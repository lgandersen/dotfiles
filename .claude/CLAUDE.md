# User-level CLAUDE.md

Applies to every Claude Code session on this machine.

## Code comments

- Match the comment density of the surrounding code; for new files, near zero.
- Never write comments that restate the code (`# increment i`, `# set the timeout`).
- No section-banner comments (`# --- setup ---`), no narration of changes.
- A comment must earn its line: workaround explanations, non-obvious invariants,
  references to issues/specs.
